# 测量层次、分母与实验边界

## 四种计数分别回答不同问题

- 应用正文：只在长度及内容校验完成后计入成功交付分母。应用层自动重试未启用。
- 专用 L3：测试规则计入的 IP 字节，包括握手、ACK、头部和重发。它不是纯重传字节，也不是云厂商的账单口径。
- 设备 NIC：接口窗口差分，包含背景业务及控制流量，不能全部归给实验。
- 预算：可将多端 RX+TX 保守累加，同一数据可能被重复观察；这种总数不能用作唯一业务字节或账单。

`Mbps = 已校验正文字节 × 8 / 秒 / 1,000,000`。MB 使用十进制，MiB 使用 1,048,576 字节。正文长度、持续秒数和无量纲倍率保留源数值精度，展示表按需要四舍五入。分位数采用排序后线性插值，成功样本中位数不包含失败；成功率、失败费用及缺测另行显示。

发送倍率是发送端专用 L3 TX / 已校验正文，失败时该倍率为空。重复载荷比例可能以全部发送载荷或唯一载荷为分母，二者不相同；比较时必须阅读对应字段定义。QUIC 判失事件和收发计数差均不能直接当作物理网络丢包率。

## 两跳成本需要拆开方向

下载含源站到网关、网关到客户端两段；上传方向相反。只测网关到源站的一跳时，尚未测得网关到客户端的费用。源站 TX 与网关 TX 分开保存。

完整链路汇总的成本指标为：所有已开始文件尝试的网关 TX（包括失败）/ 成功文件正文总字节。准备失败另列条数及消耗，不混成协议传输失败，也不凭空丢弃。低成本但交付不完整的方案不自动优于全部完成的方案。

控制器上传成本将所有上传尝试 TX 除以成功上传正文；下载反向成本将全部下载阶段网关 TX 除以成功下载正文。此成本不包括尚未测量的最终用户转发，也不包含会话外全部管理费用。

## 实验粒度与可比性

- 会话只有上传和下载均成功且各自达到阈值才算双向达标。两个阶段顺序执行，并不证明同时全双工容量。
- 多次请求共用路径、时间块或连接状态，不能当作同等数量的独立随机实验单元。
- 探索、主比较、辅助中断块、补测和准备失败有独立标记。原失败没有被后续成功覆盖。
- 详细帧日志会影响 CPU、管道和发送节奏。开启日志与静默样本分层，不能混算为日常表现。
- 容器套接字的拥塞算法回读不等于宿主用户态网络转发器的公网 TCP 算法。GSO/GRO、捕获丢样及异步读数也限制字节归因。
- 部分模式只在测试连接启用 BBR，另一端仍为 CUBIC；不能统一描述成双向 BBR。

数据只保留到月份的采集范围；精确时间、主机/网络身份和连接明细已移除。因此公开结果不能用于复建运营时间线、匹配外部账单或重现原部署。后续若需重新实验，应自行准备隔离端点、认证、限额及新排程；这里提供的是离线结果验证，不是可直接执行的远端操作脚本。
