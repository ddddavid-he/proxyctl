# 实验结果的公开边界

公开内容是技术结果，不是运维档案。保留实验方法、软件版本、逻辑角色、正文大小、持续时间、字节计数、失败、统计分母和限制条件；使用匿名代号，不公开代号与真实设备或地点的对应关系。

## 从原材料中移除的风险

| 类型 | 处理 |
| --- | --- |
| 公网、客户端及内网地址，证书域名、订阅入口 | 不导出；逻辑角色替代 |
| 设备、主机、容器、账号或工作区标识 | 不导出；匿名客户端或节点代号替代 |
| 逐连接五元组、访问域名、URL、账号关联及地理位置 | 不导出；只保留实验计量或节点级汇总 |
| 云资源 ID、账单账号、费用明细及精确运营时间 | 不导出 |
| 凭据、私钥、认证头、完整配置、主机密钥与证书副本 | 不随结果发布 |
| 生产变更、备份位置、SSH 目标、恢复脚本和二进制 | 留在私有原材料中，公开版只描述测试行为 |
| 旧 Git 分支、提交、托管缓存和旧附件 | 需要独立的历史清理与访问复核；当前文件匿名化不证明历史已清除 |

## 数据保留与来源

公开 JSON 通过显式字段白名单导出，不复制原始字符串树。精确时间删除，采集月份保留；失败保留成功标记、实际计数字段与缺测，错误原文移除。准备失败、工程中断、探索与主比较单独保留，不能只导出最好结果。

[来源目录](provenance.json)使用逻辑证据 ID 标明各数据集的内容粒度。私有路径和原始文件哈希映射不提交；公开 [manifest.json](manifest.json)验证公开文件内容，不能验证未公开源捕获的真实性。原始证据仍由维护者本地保存，本次整理没有改写原材料。

## 可以复算什么

离线验证可重算公开字段内的成功率、方向/会话分母、吞吐、字节倍率、失败成本和矩阵覆盖，并检查常见地址、域名和身份泄漏模式。检查不是完整的秘密识别器，也不是实验数据真实性的密码学证明；新增字段与自由文本仍须人工审阅。

原始运维和观测目录继续忽略，经过整理的本目录正常进入版本管理。忽略规则不能阻止强制添加、旧分支再次推送、已有克隆传播或按旧 SHA 访问；这些风险必须另行处理。
